ROBOFEST 5.0 · COMPETITION

VARUNA — Vision-Guided Autonomous Underwater Vehicle (AUV)

VARUNA is a compact, fully autonomous underwater vehicle designed for reliable operation in low-visibility aquatic environments. Its architecture combines a waterproof PVC pressure hull, a transparent vision dome, and a six-thruster holonomic propulsion system, enabling precise navigation, perception and underwater manipulation.

COMPUTE

NVIDIA Jetson Nano — high-level vision, autonomy and AI inference.
STM32 Nucleo-64 — real-time motor control, PID loops and low-latency I/O.

SENSORS

Underwater HD camera · BNO055 IMU · Bar30 pressure sensor · dual hydrophones supporting TDOA-based acoustic localization.

ACTUATION

6 BLDC thrusters for 3D holonomic maneuvering · worm–spur gear gripper for underwater object interaction.

POWER

14.8V Li-Po battery for propulsion · isolated power banks for Jetson Nano and STM32.

AUTONOMY STACK

ROS 2 / Nav2 for mission planning and navigation · OpenCV + transformer-based detectors for gate, mat and object recognition · EKF/UKF multi-sensor fusion · PID stabilization for depth, pitch, roll and thrust · behavior-tree navigation.

APPLICATIONS

Underwater structure inspection · environmental and ecological monitoring · marine research and sampling · autonomous underwater robotics competitions.

CURRENT STATUS

Completed: system ideation, architecture and subsystem design, waterproofing and buoyancy strategy, sensor pipeline design and project timeline. The next phase requires funding support for fabrication, hardware integration and controlled pool testing.

ROBOFEST 5.0 · COMPETITION PROJECT

VASUDHA

Compact precision-agriculture concept robot using AI-based plant analysis, autonomous navigation and controlled micro-dosing to reduce chemical use and improve targeting.

PROPOSED ARCHITECTURE

Jetson Orin Nano · ESP32 · Arduino Uno · camera · 2D LiDAR · MPU-9250/9620 IMU · custom 8-sensor IR array · capacitive tank-level sensing · 4 geared DC motors · mini MacPherson suspension · diaphragm pump + solenoid valves · servo-aligned nozzles · 12V Li-Po with BMS.

AUTONOMY & PRECISION AGRICULTURE

ROS 2 Nav2 · YOLOv8/TensorRT · RTAB-Map SLAM · EKF fusion · PID control · hybrid IR-line + LiDAR navigation · health-aware micro-dosing · reduced overspray · digital field maps.

CURRENT STATUS

Ideation stage: concept created, mechanical/CAD design completed, sensor and electronics architecture defined, autonomy pipeline planned and development roadmap established. Fabrication and field testing are planned for the next phase subject to resources and approvals.

ROBOFEST 5.0 · COMPETITION PROJECT

KARNA — Kinetic Autonomous Robot for Navigation & Assault

An advanced intelligent ground vehicle designed for RoboFest Gujarat 5.0, combining a strong MS sheet-metal chassis, independent suspension and a 4-wheel BLDC drive system for stable movement over rough terrain.

WHAT KARNA DOES

Navigates autonomously through complex and uneven terrains · detects obstacles, identifies lanes and makes path decisions using AI vision + LiDAR · performs real-time surveillance and controlled grenade-ball launching.

MECHANICAL PLATFORM

MS sheet-metal chassis · independent suspension · 4-wheel BLDC drive system engineered for rough-terrain mobility and stable operation.

COMPUTE & CONTROL

NVIDIA Jetson Nano for AI-based vision, lane detection and decision-making · STM32 microcontroller for real-time motor control.

SENSING

360° LiDAR · depth camera · TFmini LiDAR · IMU for environmental mapping, obstacle avoidance and smooth navigation.

SURVEILLANCE

Mounted camera providing continuous real-time surveillance for remote monitoring and mission awareness.

DEPLOYMENT MECHANISM

Stepper-driven grenade chain mechanism and lead-screw launching system for controlled and precise projectile deployment in the competition context.

APPLICATION AREAS

Defense-oriented robotics concepts · search-and-rescue operations · hazardous inspections · autonomous field missions.

PROJECT SUMMARY

KARNA demonstrates an integrated approach to mechanical design, intelligent software and advanced sensing, combining autonomous mobility, AI-assisted perception, navigation and remote surveillance in a single ground-robotics platform.

MEMBER'S PROJECT

FusionToDescription — Autodesk Fusion 360 → ROS 2 Description Package Exporter

FusionToDescription is an Autodesk Fusion 360 add-in that automates generation of ROS 2 robot description packages directly from CAD assemblies, bridging mechanical design and robotics simulation.

CAPABILITIES

Automated ROS 2 package generation · organized URDF/Xacro export · automatic mass and inertia tensors · mesh and primitive collision generation · Gazebo sensor integration · automatic ROS-GZ bridge configuration · optional ROS 2 Control support · simulation-ready packages.
